# The Cozy Bakery Corner — React Website

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Where to edit

- `src/App.jsx` → content, products, phone number, WhatsApp order message.
- `src/styles.css` → colors, spacing, typography and responsive layout.
- `public/images/` → replace the supplied bakery photos with your final product photos.

The site is responsive for desktop, tablet and mobile screens and uses WhatsApp for the order CTA.
